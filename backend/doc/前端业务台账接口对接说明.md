# 前端业务台账 / 承灾体列表对接说明

## 背景

前端灾情调查、灾害评估原先大量使用 localStorage MOCK。现已增加后端接口，并在前端实现：

**有数据 → 用真实接口；接口失败或返回空 → 回落 MOCK。**

## 启动建表

应用启动时 `BizSchemaInitializer` 自动检测并创建（达梦）：

- `T_BIZ_FRONTEND_DATA`：通用业务 JSON 台账（对应前端 surveyBase 各 dataType）
- `T_BIZ_REPORT_ARCHIVE`：评估报告归档

SQL 脚本副本：`disaster-survey-admin/src/main/resources/sql/init_biz_frontend.sql`

## 新增接口（context-path `/zuul`）

### 业务台账 CRUD

Base：`/web-disaster-evaluate/web/disaster/evaluate/bizdata`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/list?dataType=&keyword=&extraType=` | 列表 |
| POST | `/queryWithPage` | 分页 |
| GET | `/getById?id=` | 详情 |
| POST | `/save` | 新增 `{ dataType, data }` |
| POST | `/update` | 更新 |
| GET | `/delete?id=` | 删除 |
| POST | `/batchSave` | 批量写入 `{ dataType, list }`（运维「同步 MOCK 到服务器」） |
| POST | `/reportArchive/save` | 归档报告 |
| GET | `/reportArchive/list` | 归档列表 |
| GET | `/reportArchive/getById?id=` | 归档详情 |

`dataType` 与前端一致，例如：`county` `town` `seawall` `rsScene` `assessSar` `assessTyphoon` `assessOvertop` `assessIntegrate` `assessDamage` 等。

### 承灾体列表（已有库 DB_DANGER）

Base：`/web-disaster-evaluate/web/disaster/evaluate/exposure`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/list?exposureType=&keyword=` | 列表，字段对齐前端台账 |

`exposureType`：`Dike`/`Fishery`/`CultureArea`/`TouristArea`（也兼容 `seawall`/`fishing`/`mariculture`/`tourist`）

原有 `/tree` 不变。

### 调查对象档案（现场资料 / 附件 / 核对归档）

Base：`/web-disaster-evaluate/web/disaster/evaluate/dossier`  
表：`T_BIZ_HAZARD_DOSSIER`（启动自动建表）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/get?hazardType=&hazardName=` | 获取档案；无记录 `data=null` |
| POST | `/save` | 保存完整档案 JSON（含 materials/attachments） |
| GET | `/listArchived?keyword=` | 已归档列表 |

前端首次打开某承灾体详情时：若后端无记录，用 MOCK 种子生成并 `save` 回写；之后核对/归档均走 `/save`。

## 前端改动要点

- `src/api/bizRemote.js`：远程调用
- `src/api/withMockFallback.js`：空/失败回落
- `src/api/surveyBase/index.js`、`survey/index.js`、`assessment/index.js`：统一优先远程
- `src/utils/request.js`：支持 `hideErrorMsg`，探测接口失败不弹红字

## 灌数建议

1. 在运维管理页新增/编辑台账 → 会尝试写入 `T_BIZ_FRONTEND_DATA`
2. 或直接向 `T_BIZ_FRONTEND_DATA` 插入 `DATA_TYPE` + `JSON_DATA`
3. 四类承灾体若 `DB_DANGER` 已有数据，调查/评估会优先读 `/exposure/list`
